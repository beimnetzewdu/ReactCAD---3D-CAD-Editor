# ReactCAD - Browser-Based CAD Editor

A minimal but structurally solid browser-based CAD editor built with React and Three.js (plain Three.js, no React Three Fiber).

🚀 Features
🧱 Shape Creation

Create Box, Sphere, and Cylinder primitives

Explicit face and edge selection with color highlights

🟢 Face/Edge

🟡 Shape

🎯 Selection System

Shape, Face, and Edge selection modes

Displays properties: area, normal, edge length, etc.

Raycasting ensures precise picking

✏️ 2D Sketch & Extrusion

Sketch Mode on XZ-plane with grid snapping

Draw rectangles or circles, preview in real time

Extrude 2D sketches into 3D models

🔧 Transformations

Move, Rotate, and Scale objects

Real-time updates via sidebar inputs

🧾 Properties Panel

Shows details like:

Type, ID, Position, Rotation, Scale

Face area, Edge length, and geometry parameters

💾 Import / Export

Export full scene as JSON

Import saved JSON files

Example scenes included in /examples

🎥 Camera Controls

Orbit: Alt + Drag

Pan: Shift + Drag

Zoom: Mouse Wheel
